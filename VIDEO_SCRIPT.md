# PrepMe — 3 to 4 Minute Walkthrough Video Script

Follow this rehearsed script when recording your 3–4 minute walkthrough video for the **Open-Source AI Side Hustle** submission.

### Preparation Before Recording
1. Ensure Ollama is running (`ollama run gemma2:9b`) or cloud open-weight provider is configured in `.env`.
2. Start MongoDB, backend server (`npm run dev:server`), and web frontend (`npm run dev:web`).
3. Have `http://localhost:3000` open in your browser in full screen.
4. Have a sample job description and company URL copied to your clipboard (or use one from `test/fixtures/cases.json`).

---
